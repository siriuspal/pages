Home Blinds privacy

Last updated 1 November 2026

  • Home Blinds is a private Alexa skill. It is not published, and only its owner's household can use it.
  • It reads one thing from Amazon: your Amazon user ID, to check that a request comes from the owner's account.
  • Nothing is sold, shared or used for ads.

What the skill does

Home Blinds lets Alexa open, close and set the position of window blinds in one home. Alexa sends each command to a small function, which passes it to that home's own home automation system.

Information used

  • Amazon user ID, through Login with Amazon when you link the skill. The skill uses it to accept the owner's account and refuse any other.
  • The command itself: which blind, and open, close or a position. It is used only to move the blind.

The skill does not ask for your name, email address, voice recordings, location or contacts. Voice recordings stay with Amazon under Amazon's Alexa privacy settings.

What is kept

The skill has no database. Its function writes short technical logs (errors, and the Amazon user ID of a refused request), which are deleted after 30 days.

Sharing

Information is not sold or shared with anyone. It passes only between Amazon, the skill's function, and the home's own system.

Stopping

Disable the skill in the Alexa app (Skills & Games, then Your Skills) to unlink it. The skill then receives nothing from your account.

Changes

If this policy changes, the date at the top changes with it.
